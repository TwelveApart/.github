# .github

Organization-wide files for TwelveApart.

- `profile/README.md` is the public organization profile at
  [github.com/TwelveApart](https://github.com/TwelveApart). Members see a
  separate profile from the private `.github-private` repository.
- `.github/pull_request_template.md` is the default pull request template for
  every TwelveApart repository that does not have its own.
