# TwelveApart

Two brothers, twelve years apart, exploring how increasingly capable models
change the products we build, the way we build them, and the organizations that
build them.

An independent AI product and engineering studio run by
[Brandon](https://twelveapart.com/brandon/) and [Kai](https://twelveapart.com/kai/).

- **[twelveapart.com](https://twelveapart.com)**: essays in
  [Ideas](https://twelveapart.com/ideas/), experiments in
  [Lab](https://twelveapart.com/lab/), and case studies in
  [Work](https://twelveapart.com/work/).
- **[mandem](https://github.com/TwelveApart/mandem)**: local-first agent
  orchestration for disciplined, restart-proof software delivery. Open source.
- **[Work with us](https://twelveapart.com/work-with-us/)** if you have a
  product problem that models have changed.
